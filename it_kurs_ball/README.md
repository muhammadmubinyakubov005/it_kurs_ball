# IT Kurs Gamifikatsiya va Balli Reyting Tizimi (Telegram Mini App) 🚀🎮

Yosh dasturchilar va o'quvchilarni darslarga qiziqtirish, ularda sog'lom raqobat uyg'otish uchun zamonaviy Cyberpunk/Gaming uslubidagi interaktiv Telegram WebApp.

---

## 🌟 Nimalar mavjud:

1. **👤 O'quvchi Profili:**
   - Shaxsiy avatar va unvoni (Level 1: Novice Coder, Level 2: Code Ninja, Level 3: Bug Hunter, Level 4: Cyber Master, Level 5: Tech Legend).
   - Ballar hisobi (`🪙 XP Ball`) va keyingi darajagacha boruvchi progress bar.
   - Ketma-ket dars qoldirmaslik seriyasi (`🔥 7 kunlik streak`).
   - Ballar tarixi (Uy ishi, loyiha, faollik).

2. **🏆 Jonli Guruh Reytingi (Leaderboard):**
   - 1, 2, va 3-o'rinlar uchun Oltin, Kumush va Bronza kubokli podium.
   - Guruhdagi barcha o'quvchilar ro'yxati, har bir bola o'z o'rnini ko'rib turadi.

3. **🎯 Quests & Missiyalar:**
   - Uyga vazifani a'lo topshirish (+15 XP).
   - Darsdagi faollik (+10 XP).
   - Mustaqil mini-loyiha qilish (+35 XP).
   - Nazorat testida 90%+ olish (+25 XP).

4. **🎁 IT Sovg'alar Do'koni (Market):**
   - Bolalar to'plagan ballariga stikerlar, shokolad, 1 soat game time yoki brendli futbolka sotib oladi.

5. **👨‍🏫 O'qituvchi Boshqaruvi (Admin Panel):**
   - Tepada **«👨‍🏫 O'qituvchi»** tugmasi bor.
   - O'quvchini tanlab: `[ +5 Faollik ]`, `[ +10 Uy ishi ]`, `[ +20 Loyiha ]`, `[ -5 Intizom ]` tugmalari bilan 1 soniyada ball qo'shiladi va saqlanadi!
   - Yangi o'quvchi qo'shish imkoniyati.
